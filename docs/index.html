About / How to Use

How to use: Adjust arrival rate (λ), per-lane service rate (μ), security lane count (c), and surge multiplier, then click Start. Use Pause to inspect metrics and Reset to restart cleanly.

Reference consistency: At default settings (λ = 18.0/min, μ = 3.0/min, c = 7 lanes, surge = 1.0x), steady-state mean queue wait matches the notebook reference result (Wq ≈ 0.20 min, 95th-percentile wait ≈ 0.78 min, peak queue ≈ 27 spectators).

Try this scenario: Keep λ = 18/min, μ = 3/min, surge = 1.0x, and test c = 6 lanes (critically loaded, ρ = 1.00) versus c = 7 lanes (ρ = 0.86) to see wait times drop well below 10 minutes.

Limitations: Uses exponential inter-arrival and service times and a single-gate abstraction without spatial walking dynamics or multi-gate diversion.
